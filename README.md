# LiteBrowser

A lightweight Chrome-style browser that uses fewer resources.

---

## Quick Start (2 Steps)

### Step 1: Install Node.js
Download and install from: **https://nodejs.org**

Choose the **LTS** version and follow the installer prompts.

### Step 2: Run the Browser
Open this folder in File Explorer, then **double-click `install.bat`**

After installation completes, **double-click `start.bat`** to launch.

---

## Manual Installation

Open Command Prompt in this folder and run:

```
npm install
npm start
```

---

## How to Use

| What | How |
|------|-----|
| New tab | Click + button or press `Ctrl+T` |
| Close tab | Click X on tab or press `Ctrl+W` |
| Type address | Click address bar or press `Ctrl+L` |
| Search | Type in address bar and press Enter |
| Go back | Click back arrow or press `Alt+Left` |
| Go forward | Click forward arrow or press `Alt+Right` |
| Reload page | Click reload button or press `Ctrl+R` |
| Bookmark page | Click star icon or press `Ctrl+D` |
| Full screen | Press `F11` |
| Find on page | Press `Ctrl+F` |
| Zoom in/out | Press `Ctrl++` / `Ctrl+-` |
| Settings | Press `Ctrl+,` or click menu (3 dots) |

---

## Menu (3 Dots Button)

Click the 3 dots in the top-right corner for:
- New tab / New window
- History
- Downloads
- Bookmarks
- Zoom controls
- Find in page
- Print
- Settings
- Help

## Troubleshooting

**Browser won't start?**
- Make sure Node.js is installed
- Run `install.bat` again

**Pages won't load?**
- Check your internet connection
- Press `Ctrl+R` to reload
